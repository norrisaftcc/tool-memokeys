# MemoKeys MVP - macOS Floating Overlay

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the app
python minimal.py
```

## Features
- Floating window that stays on top
- Shows keyboard shortcuts as you type
- 100 lines of code

## Requirements
- macOS only
- Python 3.8+
- Accessibility permissions (System Preferences > Security & Privacy > Accessibility)

## What it does
1. Shows a small floating window
2. Displays "Press ⌘+C" 
3. Updates to show what keys you're actually pressing
4. That's it - pure MVP!
